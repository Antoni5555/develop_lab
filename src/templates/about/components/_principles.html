Принципы

  1. 01

    Один магазин на все курсы

    Задачи — из backend интернет-магазина: заказы, товары и пользователи знакомы с первого курса.

    Практика первична

    Теории ровно столько, чтобы решить задачу и не споткнуться на собеседовании.

    Код не уходит на сервер

    Python и SQL работают прямо в браузере. Сервер видит только прогресс и заметки.

    Быстро

    Тяжёлые движки грузятся только на странице тренажёра, остальное — лёгкие страницы.
