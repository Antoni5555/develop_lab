# Курс: Python (Python 3.12) — шаг 10

**Контекст:** задачи из бизнес-логики магазина: товары, корзина, заказы, оплата, доставка. Каждая задача самостоятельна, проект по ходу курса не собирается. Чем дальше раздел, тем «взрослее» инструменты: переменные и словари → функции → классы → тесты → async.
**Уровень:** курс начинается с самого начала языка, но читатель — новичок в Python, а не в компьютерах: термины (URL, сервер, форма) не разжёвываем, но и не усложняем. Глубина — в курсе «Python под капотом».
**Тренажёр:** Pyodide (Python в браузере) + виртуальные файлы.
**Источники:** `THEORY_BOOK/base_python_backend_theory/day_1_python_basics` (**D1**), `day_3_oop` (**OOP**), `day_4_async` (**ASYNC**).

**Правило последовательности:** каждая тема опирается только на темы выше. Поэтому:
- сортировка с `key=`/`lambda` идёт после «Функций»;
- свои исключения и свои контекстные менеджеры — после классов;
- venv/pip — в курсе Linux, где уже есть терминал;
- HTTP-клиенты — в курсе «Веб и HTTP».

Формат — [docs/content-format.md](../../docs/content-format.md), легенда — [00-overview.md](00-overview.md).
