# Курс: Git — шаг 30

**Контекст:** ученик ведёт репозиторий магазина: делает фичу «промокоды», чинит баг в расчёте скидки, работает в ветках, решает конфликт в `settings.py` с коллегой, открывает pull request.
**Тренажёр:** свой симулятор на JS поверх Linux-симулятора (терминал + виртуальная ФС), появляется сразу после него. Визуализация — граф коммитов (ветки, `HEAD`, позже `origin`) и три области: рабочая папка → индекс → репозиторий. Id коммитов короткие и детерминированные — их можно показывать в уроках. Задачи проверяются по итоговому состоянию репозитория. Пока симулятора нет — `quiz` (что сделает команда, порядок шагов) и `fix` (`.gitignore`, конфликт в файле, сообщение коммита).
**Источники:** `КОНСПЕКТЫ/ТЕОРИЯ/Git/Git.docx` (**GIT**) — конспект по чужому курсу: берём только порядок тем и факты, **текст и примеры пишем заново** в контексте магазина. Папки `git-*-case`, `first-project`, `movies` — копии практики того курса, не используем. Плюс `training_skills/connect_to_github.md` (SSH).

Формат — [docs/content-format.md](../../docs/content-format.md), легенда — [00-overview.md](00-overview.md).
