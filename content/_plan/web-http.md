# Курс: Веб и HTTP — шаг 35

**Зачем:** закрывает пробел между «пишу на Python» и «пишу backend». Без него непонятно, что делает сервер магазина, откуда в Django берутся `request` и `response`, почему Nginx отвечает 502, а API — 401.
**Контекст:** путь запроса покупателя: браузер → сайт магазина → API → ответ. Ученик читает и составляет HTTP-запросы к API магазина и разбирает ответы.
**Тренажёр:** реальной сети в браузере нет. Задачи — `quiz` (какой метод/код ответа), «собери запрос» (проверка по правилам), Python-задачи на `httpx` с подменой транспорта (`httpx.MockTransport`). ⚠️ Вопрос к «Разработке»: работает ли `httpx` в Pyodide.
**Источники:** почти нет — фрагменты в `training_skills/nginx_gunicorn.md` (HTTPS, коды ошибок), `КОНСПЕКТЫ/ТЕОРИЯ/FastAPI/FastAPI.docx` (проверить: REST, запросы). Курс пишется с нуля.

Формат — [docs/content-format.md](../../docs/content-format.md), легенда — [00-overview.md](00-overview.md).
