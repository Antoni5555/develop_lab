# Курс: Django (Django 5.x) — шаг 50

**Контекст:** Django-приложение магазина: каталог, карточка товара, корзина, оформление заказа, личный кабинет, админка для менеджеров. Каждая задача самостоятельна. ORM изучается **внутри Django**: каждая тема ORM отвечает на потребность конкретной страницы — каталогу нужны фильтры и пагинация, списку заказов — борьба с N+1, дашборду менеджера — агрегация.
**Почему такой порядок:** сначала ученик видит, как Django отвечает на запрос (URL → view → шаблон), и только потом подключает данные. Так модели и QuerySet сразу служат странице, а не существуют сами по себе.
**Тренажёр:** Pyodide + Django + SQLite. Сервер не нужен: запрос выполняется через тестовый клиент Django прямо в браузере. Визуализация: какие SQL ушли в базу (`CaptureQueriesContext`, подсветка N+1) и какой HTTP-ответ вернулся (статус, заголовки, редиректы, HTML в изолированном iframe). Подтверждено «Разработкой»; перед этапом 5 — прототип для проверки скорости старта.
**Ограничения тренажёра для задач:** база пересоздаётся на каждый запуск (миграции не пишем руками в задачах); задача может состоять из нескольких файлов (`models.py`, `views.py`, `urls.py`, шаблон) — формат многофайловой задачи согласуем с «Разработкой».
**Опирается на:** Python (ООП, тесты), Веб и HTTP (запрос/ответ, формы, cookies, CSRF), SQL (JOIN, агрегация, транзакции, индексы).
**Источники:** `THEORY_BOOK/README.md` — подробный план Django по дням (**D1–D4**, текста нет), `practice/create_django_project.md` — проект, settings, шаблоны (**PRJ**), `practice/create_foodgram` — проектирование моделей, код портфолио (`settings/base|development|production`) как пример.

Формат — [docs/content-format.md](../../docs/content-format.md), легенда — [00-overview.md](00-overview.md).
