# Курс: Python под капотом — шаг 15

> Черновик от 2026-10-20. Курс утверждён, программа — черновик. Slug: `python-internals`.

**Зачем:** базовый курс отвечает на вопрос «как пользоваться», этот — «как это устроено и почему». Это вопросы, на которых теряются на собеседованиях: хешируемость, ссылки, сборщик мусора, MRO, дескрипторы, GIL.
**Кому:** после базового курса Python (или параллельно, с его ООП-раздела).
**Контекст:** тот же магазин. Пример: кэш товаров течёт по памяти; `(product_id, size)` как ключ словаря; два заказа «делят» одну корзину.
**Тренажёр:** Pyodide — это настоящий CPython, поэтому `id`, `sys.getrefcount`, `gc`, `weakref`, `dis` работают. Главный тип задач — **«предскажи вывод»**: ученик пишет ответ, тренажёр запускает код и показывает разницу. Именно так задают вопросы на собеседованиях.
**Источники:** куски в `day_1_python_basics/01, 03, 05` (hashable, коллизии, позднее связывание) и `day_3_oop/02–04` (дескрипторы, MRO). Остальное пишется с нуля.

### Как делим материал с базовым курсом
| | Базовый Python | Python под капотом |
|---|---|---|
| Вопрос | «как пользоваться» | «как устроено» |
| Пример | `dict` хранит пары, ключ должен быть неизменяемым | хеш-таблица, `__hash__`/`__eq__`, коллизии, почему список не может быть ключом |
| Граница | всё, что junior обязан знать для работы | детали CPython, которые объясняют поведение |

В конце каждого урока базового курса — блок **«Глубже»**: 1–2 предложения и ссылка на тему этого курса. Так база не раздувается, а связь между курсами видна.
