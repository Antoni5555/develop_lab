# Курс: Linux-терминал — карта

Источники: почти нет. Есть только:
- `training_skills/connect_to_github.md`, `connect_to_server.md` — SSH-ключи (инструкции)
- `training_skills/nginx_gunicorn.md` — разделы «SSH», «Медиафайлы: права», команды по ходу деплоя
- `Linux_useful_skill/edit_img_video.md` — ffmpeg, **не берём**

Ниже — моё предложение программы. Почти всё ❌.

## 1. Знакомство
- Терминал, shell, команда + аргументы + флаги; `man`, `--help` ❌
- Файловая система: `/`, домашняя папка, абсолютный/относительный путь ❌

## 2. Навигация и файлы
- `pwd`, `ls`, `cd` ❌
- `mkdir`, `touch`, `cp`, `mv`, `rm` (и опасность `rm -rf`) ❌
- `cat`, `less`, `head`, `tail` ❌

## 3. Поиск и обработка текста
- `find`, `grep` ❌
- Перенаправление `>`, `>>`, конвейер `|` ❌
- `wc`, `sort`, `uniq`, `cut` ❌

## 4. Права и пользователи
- `rwx`, `chmod`, `chown` 🟡 (кусок в `nginx_gunicorn.md` и `connect_to_server.md` — `chmod 600` для ключа)
- `sudo`, root ❌

## 5. Процессы и окружение
- `ps`, `top`, `kill` ❌ — в браузере частично (имитация)
- Переменные окружения, `export`, `.env` 🟡 (`nginx_gunicorn.md` §5)
- `systemctl` для сервисов 🟡 (по ходу деплоя) — ⚠️ в тренажёре только теория

## 6. Работа с сервером
- SSH, ключи 🟡 (`connect_to_*.md`) — теория, без задач в тренажёре
- Архивы `tar`, загрузка `curl`/`wget` ❌

## Итог
Курс пишется с нуля. Для тренажёра (дерево файлов с подсветкой) подходят разделы 1–4; 5–6 — в основном теория.
