## Теория
Функция — именованный блок кода, который принимает входные данные (**параметры**), что-то делает и **возвращает** результат. Её определяют один раз через `def`, а вызывают сколько угодно раз по имени со скобками. В backend почти вся логика живёт в функциях: посчитать сумму заказа, применить промокод, проверить остаток — каждое действие оформляют функцией с понятным именем.

Функции дают три вещи: код не повторяется, у действия появляется имя (`calc_total` понятнее десяти строк цикла), а функцию можно проверить отдельно — с этого раздела задачи проверяются тестами, которые вызывают ваши функции. Главное различие, на котором ошибаются новички: `return` **возвращает** значение вызывающему коду, а `print` только **выводит** текст на экран. Функция без `return` возвращает `None`.

## Наглядно
**Таблица 1.** Из чего состоит функция.

| Часть | Пример | Что делает |
|---|---|---|
| заголовок | `def calc_total(prices):` | имя функции и её параметры |
| docstring | `"""Сумма цен позиций корзины."""` | описание для людей и инструментов |
| тело | строки с отступом | выполняются при **вызове**, а не при определении |
| `return` | `return total` | возвращает значение и сразу завершает функцию |
| вызов | `calc_total([1499, 490])` | выполняет тело с конкретными аргументами |

**Таблица 2.** `return` и `print` — разные вещи.

| | `return total` | `print(total)` |
|---|---|---|
| Что делает | передаёт значение вызывающему коду | выводит текст на экран |
| Можно сохранить результат | `x = calc_total(...)` — в `x` значение | в `x` будет `None` |
| Завершает функцию | да | нет |
| Где нужно | почти всегда — в логике | для отладки и CLI-скриптов |

## На практике
Задача: вынести расчёты корзины в функции — форматирование цены, сумму, проверку бесплатной доставки, самую дешёвую и дорогую позиции.

### Шаг 1. Определяем и вызываем функцию
Функция форматирования цены — один параметр, одно возвращаемое значение:
```python
def format_price(price):
    return f"{price} ₽"

label = format_price(1499)
print(label)
print(format_price(5990))
```
Результат:
```
1499 ₽
5990 ₽
```
`def` только создаёт функцию; тело выполняется, когда функцию вызывают — `format_price(1499)`.

### Шаг 2. Возвращаем результат расчёта
Сумма корзины: локальная переменная `total` живёт только внутри функции, наружу уходит значение через `return`:
```python
def calc_total(prices):
    total = 0
    for price in prices:
        total += price
    return total

print(calc_total([1499, 490, 390]))
print(calc_total([]))
```
Результат:
```
2379
0
```

### Шаг 3. Завершаем функцию раньше
`return` сразу выходит из функции — удобно для ранних проверок:
```python
def is_free_delivery(total):
    if total >= 3000:
        return True
    return False

print(is_free_delivery(3500), is_free_delivery(1200))
```
Результат:
```
True False
```
Короче — вернуть само условие: `return total >= 3000`.

### Шаг 4. Видим, что без return получается None
Функция печатает сумму, но ничего не возвращает:
```python
def print_total(prices):
    total = 0
    for price in prices:
        total += price
    print(total)

result = print_total([1499, 490])
print(result)
```
Результат:
```
1989
None
```
На экране сумма есть, а в `result` — `None`: дальше в коде её нельзя использовать.

### Шаг 5. Возвращаем несколько значений
`return a, b` возвращает кортеж — его удобно распаковать:
```python
def price_range(prices):
    return min(prices), max(prices)

cheapest, priciest = price_range([1499, 490, 5990])
print(cheapest, priciest)
```
Результат:
```
490 5990
```

### Шаг 6. Документируем функцию
Строка в тройных кавычках сразу после заголовка — **docstring**; её показывают IDE и `help()`:
```python
def apply_discount(price, percent):
    """Цена со скидкой percent процентов, с округлением вниз до рубля."""
    return price * (100 - percent) // 100

print(apply_discount(1499, 10))
print(apply_discount.__doc__)
```
Результат:
```
1349
Цена со скидкой percent процентов, с округлением вниз до рубля.
```

## Частые ошибки
- **`print` вместо `return`.** Значение выводится на экран, но функция возвращает `None` — его нельзя сохранить, сложить, проверить тестом.
- **`return` внутри цикла.** Функция выходит на первой итерации — посчитается только первый элемент. `return` итога — после цикла, без отступа тела цикла.
- **Ветка без `return`.** Если в одной из веток `if` нет `return`, на этих данных функция вернёт `None`.
- **Имя без скобок.** `calc_total` — сама функция, `calc_total(prices)` — её вызов. Забытые скобки — функция не выполняется.
- **Определение после вызова.** Функцию нужно определить (`def` должен выполниться) до того, как её вызывают, иначе `NameError`.

## Итог
**Определение и вызов**
- `def имя(параметры):` + тело с отступом; тело выполняется только при вызове `имя(аргументы)`.
- Docstring — первая строка тела в тройных кавычках.

**Результат**
- `return значение` — передать результат и сразу выйти из функции.
- Без `return` (или с пустым `return`) функция возвращает `None`.
- `return a, b` — кортеж; распаковывается при вызове.

**Привычки**
- Функция возвращает результат, а не печатает его.
- Каждая ветка, где функция должна дать ответ, заканчивается `return`.

## Вопросы на собеседовании
<details><summary>Что возвращает функция без `return`?</summary>

`None`. Так же ведут себя пустой `return` и выход из функции по концу тела.
</details>

<details><summary>Как вернуть из функции несколько значений?</summary>

Перечислить их через запятую: `return a, b`. Возвращается один объект — кортеж `(a, b)`, который при вызове удобно распаковать: `x, y = f()`.
</details>

<details><summary>Чем параметр отличается от аргумента?</summary>

Параметр — имя в определении функции (`def f(price)`), аргумент — конкретное значение при вызове (`f(1499)`). При вызове аргументы связываются с параметрами.
</details>
